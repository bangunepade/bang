BANG BNG Layer 1 Network

Target launch: November 2026. This is the current target, not a guarantee; the launch date may change if testing or security work requires more time.

Once the BANG BNG L1 network is live and external-wallet support is verified, users are intended to be able to transfer BNG to compatible external wallet addresses they choose. Transfers will depend on the network being operational, published network details, wallet configuration, and successful testing. Do not send assets to an address until compatibility and network details are officially confirmed.
